# minidesafiohtml
Mini-desafio HTML: Portfólio
🌐 Portfólio Pessoal

Este é um projeto de Portfólio Pessoal desenvolvido em HTML, criado para apresentar informações sobre minha trajetória, projetos desenvolvidos e um formulário para contato.

📌 Estrutura do Portfólio

O portfólio está organizado em três seções principais:

Sobre Mim: Apresentação pessoal e breve resumo profissional.

Meus Projetos: Tabela detalhada contendo o nome do projeto, tecnologias utilizadas, status atual de desenvolvimento e link de acesso.

Entre em Contato: Formulário funcional com campos para nome, e-mail, assunto e mensagem.

🛠️ Tecnologias Utilizadas

HTML5: Estruturação semântica da página (uso de tabelas, formulários e marcas de texto).

📂 Como Executar o Projeto

Baixe ou clone este repositório para o seu computador.

Localize o arquivo index.html.

Abra o arquivo dando um duplo clique ou utilizando qualquer navegador web de sua preferência (Chrome, Firefox, Edge, Safari).
